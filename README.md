# SE2303大作业 校园心理健康互助社区—后端微服务
启动脚本：

```make bot```
启动bot-service

```make es```
运行脚本，部署ElasticSearch容器

```make community```
启动community-service

```make mood```
启动mood-service

```make notification```
启动notification-service

```make user```
启动user-service

```make alert```
启动alert-service

```make inspection```
启动inspection-service

```make talk```
启动talk-service
